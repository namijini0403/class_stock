## 발견 사항과 수정

1. 운영 교사 명렬표는 요청 시세 캐시가 비어 있으면 매입가로 평가했다. main에 있던 공식 시세 맵 평가를 배포하고, 양수의 `+` 표시와 손익 금액을 추가했다. 시세 미확인은 0%로 확정하지 않고 안내한다. 아직 학생이 접속하지 않아 적용 전인 기업행동도 명렬표 평가에 반영한다.
2. 기존 지급은 학생마다 별도 커밋했다. 지급 대상·학생 상태·명령 기록·감사 기록·재시도 영수증을 하나의 트랜잭션으로 저장한다. 같은 요청 번호의 동시 재시도는 한 번만 지급하며, 권한 밖 학생이나 삭제된 학생이 섞이면 전부 거부한다. 학생 행은 ID 순으로 잠근다.
3. 실제 신고 사례와 일치하는 기록은 지급 당시 등록된 학생에게 모두 반영되었고, 미지급자는 이후 가입자였다. **학급 전체 지급** 옵션은 현재 명단을 서버에서 확정하고 신규 가입자 초기 자본금도 함께 올린다. 가입과 지급은 같은 학급 행을 잠가 동시 실행 시 중복·누락을 막는다. 기존 선택 지급은 선택된 현재 학생만 대상으로 유지한다. 과거 지급 보정은 별도로 대상을 확인해야 한다.
4. 로그인 입력의 한글 조합 차이(NFC), 전각 영문·숫자(NFKC), 주변 공백을 보정한다. 기존 조합형 닉네임도 찾아 PIN을 검증하고, 동일 표기 계정이 둘이면 임의로 선택하지 않는다. 학교 공유 IP 제한 확대는 기존 main 수정에 포함되어 있다. 서로 다른 기기의 토큰이 동시에 유효한지 검사했다.
5. 국내 목록 약 2,800개 중 첫 화면 12개만 보이던 탐색을 검색어 없는 전체 목록·40개씩 더 보기·코넥스 필터로 확장했다.
6. 교사 계정 재설정·담당 반 변경 시 token_epoch를 올려 이전 권한 토큰을 폐기한다. 음수·소수 초기 자본금과 소수 지급액을 거부한다. 지급 취소 뒤 명렬표도 갱신한다.

## 범위와 주의점

- 미국 주식은 현재 지원하지 않는다. 국내 코드·원화·금융위원회 일별 시세만 처리하도록 기존에 설계되어 있다. 별도 공급자의 사용 조건과 API, USD/KRW 환율 시점, 원화 반올림, 미국 거래일·기업행동을 정한 뒤 확장해야 한다. 국내 목록에 미국 종목명을 억지로 넣지는 않았다.
- 전체 지급 후 개별 지급 기록 취소는 해당 학생 잔액만 되돌린다. 이후 가입자 초기 자본금 변경은 관리자 학급 설정에서 별도 처리한다. 화면에 이를 안내한다.
- 기기별 로그인 실패의 모든 원인을 재현한 것은 아니다. 입력·공유 IP·토큰 동시 사용 경로를 검증했으며, 계정별 잠금이나 다른 서버 주소 사용 등은 실제 실패 조건이 있으면 추가 확인한다.
- 감사와 테스트에 필요한 집계만 확인했고 학생 이름·PIN·비밀번호·접속 문자열을 이 문서에 저장하지 않았다.

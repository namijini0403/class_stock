# 미국 주식 설정 — 3.4.0

미국 10종목(애플, 마이크로소프트, 엔비디아, 알파벳, 아마존, 테슬라, 메타, 디즈니, 코카콜라, 나이키)의 검색·원화 모의 거래·달러 일봉·교사 평가액 계산을 구현했다. 공급자 연결 전에는 종목 목록과 준비 안내를 표시하고 주문을 차단한다.

## 가격 확인 횟수

하루 24회 **API 요청 한도**와 하루 24번 **전체 가격 갱신**은 다르다. 이 구현은 종목 10회 + USD/KRW 환율 1회 = 정상 갱신당 11회 요청을 사용한다. 가격과 환율이 모두 검증되면 전체 기준가를 한 번에 교체한다.

- 한국시간 화요일~토요일 오전 9시부터 새 자료 확인. 서버가 늦게 시작하면 해당 시간 이후 확인한다.
- 서버 전체에서 직전 24시간 최대 24회. 실패 요청도 계산하며 PostgreSQL에 예약을 먼저 저장해 재시작·다중 인스턴스에도 한도가 유지된다.
- 요청은 1분 이상 간격, 실패 재시도는 1시간 이후. 학생 새로고침·차트 조회는 저장된 데이터만 사용한다.
- 공급자가 그날 자료를 제공하지 않으면 화면에 실제 자료 기준일이 남는다. 휴장일에 가짜 가격을 생성하지 않는다.
- 종가·환율 기준일이 7일 넘게 오래되거나 서버 갱신이 3일 넘게 없으면 신규 주문을 막는다.

전일 종가는 하루 중 계속 변하지 않으므로 시간당 1회 확인해도 시간당 새 가격이 생기지 않는다. 실제 시간당 시세를 원하면 별도 장중 데이터 상품과 거래 시간 정책이 필요하다.

## 공급자 계정 연결

1. [Alpha Vantage 키 발급](https://www.alphavantage.co/support/#api-key)에서 계정을 준비한다. 키 값은 채팅·Git에 올리지 않는다.
2. 학교 교육 프로젝트 지원을 신청하면서 `TIME_SERIES_DAILY_ADJUSTED`, `FX_DAILY`의 USD/KRW 접근과 학생 화면의 시세 표시 권한을 확인한다. Daily Adjusted는 공식 문서상 Premium이다. 일반 무료 키만으로 충분하다고 가정하지 않는다. 교육 지원이 Premium 접근까지 포함하는지도 확인한다.
3. Railway의 `class_stock` → production → Variables에 `ALPHA_VANTAGE_API_KEY`를 저장한다. 필요한 접근과 표시 권한이 확인되면 `US_MARKET_ENABLED=true`로 설정한다. 유료 계약은 별도 결정이며 코드 배포가 구독을 생성하지 않는다.
4. 재배포 후 `/api/health`의 `marketData.us`에서 `configured`, `enabled`, `ready`, `asOfDate`, `fxAsOfDate`, `requestsUsed`, `error`를 확인한다. 첫 정상 배치는 약 10분 이상 걸리며, 예약 시간 밖이면 다음 확인 시간까지 기다린다.
5. 별도 시험반에서 미국 종목 매수·매도와 교사 평가액을 확인한 뒤 수업에 사용한다.

기존 운영 계정에는 미국 API 키가 없었으므로 이 릴리스에서는 활성화하지 않았다. 개발용 가격은 로컬 격리 DB에서만 사용했으며 운영 데이터로 올리지 않았다.

## 계산과 기록

- 기존 원화 잔액을 사용한다. 달러 가격·환율을 고정소수점으로 계산하고 주문 총액에서 원 단위로 반올림한다. 같은 계산을 교사 평가와 학생 평가에도 적용한다.
- 거래 내역에 달러 가격, 환율, 환율 기준일, 가격 기준일, 기준가 묶음 ID를 보존한다. 평균 매입가는 원화 수수료 포함 가격이다.
- Daily Adjusted 응답의 **조정 전 종가**를 거래에 사용한다. 배당과 분할은 새 기준가 발행 시 한 번 반영한다. 배당은 실제 지급일 재현이 아닌 수업용 기준가 갱신 시 모의 지급이다. 단주는 원화로 정산하고, 배당·단주 실현손익도 반영한다.
- 차트는 달러 기준 조정 전 일봉이며 분할 시 가격 단절이 있을 수 있다. 최근 최대 100거래일만 가져오므로 긴 기간을 선택해도 실제 보유 범위만 표시한다.
- 장기간 중단으로 기업행동 이력을 확인할 수 없는 경우 새 가격 발행을 보류한다. 국내 자산과 거래 기록은 기존 형태로 보존한다.

## 검증

`npm run check`는 환산 반올림, 상태 보존, 일중 미완료 봉 제외, 갱신 원자성, 재시작·다중 요청 한도, 분할·배당 멱등성, 오래된 가격 차단을 검사한다.

`npm run check:classroom`은 격리된 PostgreSQL과 실제 서버 API로 미국 검색·매수·매도·환율 기록·두 기기 로그인·교사 평가·차트 통화를 검사한다. 기존 학급 지급·로그인 테스트도 함께 실행한다.

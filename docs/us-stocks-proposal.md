# 미국 주식 도입 제안 (2026-10-27)

3.4.0에서 미국 주식 기능을 구현했다. 실제 시세 활성화에는 공급자 키와 접근 권한이 필요하다. 현재 설정과 검증 내용은 [설정 안내](us-stocks-setup.md)를 참고한다. 아래는 최초 제안 기록이다.

## 권장 운영 방식

- 먼저 10~20개 종목을 교사가 선택한다. 애플, 마이크로소프트, 엔비디아, 디즈니, 코카콜라 등은 수업에서 기업을 비교하기 위한 예시이며 투자 추천은 아니다.
- 미국의 최근 완료된 거래일 종가를 하루 한 번 받아 한국 수업 시간에 공통 모의 기준가로 사용한다. 실시간 거래라고 표시하지 않는다.
- 기존 원화 잔액으로 거래한다. 화면에는 달러 가격, 적용 환율, 원화 환산 금액과 각각의 기준 시점을 함께 표시한다. 별도 달러 지갑은 첫 단계에서 제외한다.
- 가격과 환율을 묶은 서버 스냅샷을 발행하고 학생·교사 화면 및 주문 처리에 동일하게 사용한다. 미국 휴장일과 서머타임은 America/New_York 기준으로 처리한다.
- 종목 가격은 센트 또는 고정소수점, 환율도 고정소수점으로 계산한다. 거래 총액에서 한 번 원화 반올림하며 매수·매도·평가에 동일한 규칙을 적용한다. 수수료는 모의 수수료로 명시한다.
- 공급자 장애 시 마지막 가격은 기준일과 함께 조회만 허용하고, 유효한 가격·환율이 없으면 미국 종목 신규 주문을 막는다. 국내 거래는 독립적으로 유지한다.

## 데이터 공급자

공식 자료 확인일: 2026-10-27. 신청 전 최신 조건을 다시 확인해야 한다.

| 후보 | 공식 안내 | 판단 |
| --- | --- | --- |
| Alpha Vantage | 일반 무료 25회/일. 검증된 교육·오픈소스 프로젝트에 무제한 API 요청 지원 안내. 실시간·15분 지연 미국 시세는 유료 영역 | 교육 프로젝트 지원과 학생 화면 표시 권한을 문의하는 것을 우선 추천 |
| Twelve Data | 무료 Basic은 내부 비표시 용도. 외부 표시 지원 상품 별도 | 예산과 표시 권한을 확인한 후 대안으로 검토 |
| Alpaca | IEX 단일 거래소 데이터와 미국 전체 거래소 SIP 데이터가 구분됨 | 무료 IEX를 미국 전체 시장 가격으로 설명하면 안 됨. 표시 권한 별도 확인 |

20종목 가격과 환율 1건만으로 하루 약 21회 요청이 필요하다. 차트, 기업행동, 재시도가 추가되면 일반 무료 한도는 빠듯하므로 무료로 영구 운영할 수 있다고 가정하지 않는다. 모든 요청은 서버가 모아 캐시하고 API 키는 Railway 서버 환경변수에만 둔다.

교육 지원 승인과 시세 재표시 허용은 같은 의미가 아니다. 학교 앱에서 학생에게 가격을 보여주는 용도가 허용되는지 공급자에게 확인해야 한다. 환율 API의 USD/KRW 지원 및 데이터 갱신 시간도 계약·개발 전에 확인한다.

## 코드 변경 순서

1. 기존 국내 전용 필터와 6자리 코드 검사를 시장별 검증으로 분리한다. 기존 국내 보유 종목·거래 기록을 보존하면서 미국 종목 식별자를 추가한다. 단순히 종목 목록만 추가하면 현재 저장 데이터 정리 과정에서 미국 보유분이 제외될 수 있다.
2. 미국 데이터 어댑터, 일일 가격·환율 캐시, 교사 허용 종목 설정을 만든다. 거래 기록에 원래 달러 가격, 환율, 원화 체결금액, 기준 시각, 공급자를 보존한다.
3. 학생 잔액과 교사 수익률 계산을 같은 시장별 평가 함수로 통일한다. 국내/미국 탭, 통화·시세 기준일, 환율 영향을 표시한다.
4. 주식 분할과 배당을 이벤트 ID로 한 번만 반영한다. 체결은 조정 전 가격 기준으로 처리하고, 수정주가 차트를 쓰면 이를 명시한다. 배당 조정 가격과 실제 배당을 중복 반영하지 않는다.
5. 별도 시험반에서 환산 반올림, 동시 주문, 휴장·서머타임, 오래된 시세, 분할·배당 중복, 국내 자산 보존을 검증한 뒤 교사가 선택한 반부터 활성화한다.

첫 단계의 완료 조건은 기존 국내 자산에 변화 없이 미국 종목을 원화로 모의 거래하고, 두 기기 및 교사 화면에서 같은 잔액과 평가액을 확인하는 것이다.

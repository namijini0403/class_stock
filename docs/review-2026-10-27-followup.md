# 추가 코드 리뷰 — 3.3.2

검토 범위: 로그인·세션 갱신, 학생 상태 동기화, 교사 지급 취소, PIN 재설정, 기업행동 숫자 입력. 모든 코드에 결함이 없음을 보증하는 검토는 아니다.

수정 내용:

- 거래 후 늦게 도착한 조회가 이전 잔액을 덮어쓰는 문제: 상태 버전 비교로 이전 응답을 무시한다.
- 계정 전환·로그아웃 뒤 이전 요청이 상태를 복구하거나 새 계정을 로그아웃시키는 문제: 세션 세대 검사를 추가한다.
- 일시적인 인증 서버 장애로 저장된 로그인이 삭제되는 문제: 인증 거부와 네트워크·서버 장애를 구분한다.
- 지급 취소 시 현금이 부족해 일부만 회수하고 취소 완료로 처리하는 문제: 전액 회수가 불가능하면 409로 거부하고 원래 지급 기록을 유지한다.
- PIN 재설정 후 기존 로그인 잠금이 남는 문제: 새 PIN 저장과 잠금 해제를 같은 트랜잭션으로 수행한다. 기존 세션 무효화는 유지한다.
- 만료 시각이 없는 토큰이나 만료 경계 시각의 토큰을 수락하는 문제: 유한한 만료 시각과 엄격한 만료 검사를 적용한다.
- 기업행동의 무한대·잘못된 금액·0 교환비율을 등록할 수 있는 문제: 생성·수정에서 숫자 범위를 검사한다.

검증:

- npm run check: 구문, 국내 종목, 일봉 차트, 인증, 클라이언트 상태 경합 검사.
- npm run check:classroom: 격리된 로컬 PostgreSQL 스키마에서 실제 API 검증. 지급 원자성·중복 요청·동시 가입·권한·취소 경합·잠금 해제·잘못된 기업행동 입력 포함.
- 실제 학생 계정이나 잔액을 테스트 데이터로 변경하지 않는다.

미국 주식은 별도 us-stocks-proposal.md에 제안만 정리했으며 이번 버전에서 활성화하지 않았다.
